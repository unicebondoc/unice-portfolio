# Orb videos

Place the following video files in this directory (`public/videos/`). They are used in the memory orb panels (video above title, autoPlay, muted, loop). If a file is missing or fails to load, the player hides gracefully.

| File | Orb | Hint |
|------|-----|------|
| `orb1-origin.mp4` | Creative Foundations (2012) | Philippines footage, childhood, Bicol, beginning |
| `orb2-writer.mp4` | The Writer (2020) | Quiet, personal — journaling, coffee, rainy window |
| `orb3-pressure.mp4` | Corporate Discipline (2018) | Manila, office, structured, professional |
| `orb4-reinvention.mp4` | I Chose Different (2022) | Airport, Sydney, harbour bridge, ocean |
| `orb5-building.mp4` | Theory Became Real (2024) | Screen recording, code editor, terminal |
| `orb6-proof.mp4` | High Distinction (2025) | Graduation ceremony, WSU, stage |
| `orb7-work.mp4` | Core Memories (2026) | Portfolio build, code, 3D scene, or forest clip |
| `orb8-becoming.mp4` | Still Becoming (2026) | Sydney, studying, cafe, city at night |
| `root-identity.mp4` | Root identity orb | Intro clip, portrait, selfie — this is you |

URLs in the app: `/videos/orb1-origin.mp4`, etc.
