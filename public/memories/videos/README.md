# Orb videos

Place finalized orb video clips here. Naming:

- `01-orb-origin.mp4` … `08-orb-becoming.mp4` (story orbs)
- `09-orb-root.mp4` (identity/root orb)

For reliable in-browser playback, use **web-compatible MP4** (e.g. H.264 codec). Many tools can convert to this format (FFmpeg, HandBrake, or export “for web” from your editor).
