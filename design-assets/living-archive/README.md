# Living Archive art source

Original bioluminescent grove, miniature project memory spheres and a white Tyche guide, generated for Unice's hiring portfolio on 13 October 2026. The direction combines luminous ecology and translucent memory objects with the existing Core Memories forest. No characters or franchise marks were copied.

`prompts.json` preserves the exact eight generation prompts. `assets.json` records delivery dimensions, transparency, byte counts and SHA-256 hashes. PNG masters are preserved here; WebP delivery exports are served from `public/world/`. The approved portrait is reused from the owner's accepted pearl-earring/diamond-pendant image.

The illustrations set the atmosphere. Project details use actual screenshots and the shared project facts, including contribution and release boundaries. The Core Memories case thumbnail is a screenshot of the current functioning forest; its previous thumbnail is preserved here.

Browser review covered desktop, tablet and phone-width layouts; six selections and keyboard navigation; case opening; CV focus return; forest iframe focus and Escape behavior; reduced motion; asset loading; and chat opening without a paid/API message. The dated Career release receipt owns the publication and live verification evidence.

`design-assets/` is excluded from Vercel uploads. These masters remain in the repository for future revisions.
